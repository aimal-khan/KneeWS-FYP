KneeWS — proof of concept

One system, two paths. Reports teach the model during training; only images are needed when it runs. Click any feature to open its screen.

Training path · research
  1. F3 Read every training report, in whatever language it was written
  2. F4 Sort each of the 12 findings into present absent uncertain unmentioned
  3. F5 Measure how trustworthy each state is against the expert-checked subset → probability labels, with ranges
  4. F6 Train the multi-series MRI model on those probabilities
  5. F10 Race it against the same model trained on hard 1/0 labels
Deployment path · product
  1. F1 Upload a study — DICOM, NIfTI or a packaged folder
  2. F2 Reconstruct the series and slices, normalise across scanners
  3. F6 Twelve abnormality probabilities, with honest confidence ranges — no report required
  4. F8 Inspect the evidence on the slices
  5. F7 Edit and sign a grounded draft report · F9 specialist category

Confident learning → probability labels

F5, Option B — the same four rules, estimated from where the model confidently disagrees with the reports it was trained on. No expert label is spent. The 58 stay sealed until the very last step, so they can act as a referee rather than a teacher.

The confident joint — where the model disagrees with the report

Every one of the 52,188 finding-pairs is placed by what the report said and what an out-of-fold model confidently predicts. A pair only counts when the prediction clears that class's own self-confidence threshold, so a badly calibrated model cannot flood a cell.

Leakage control

The expert-checked subset is used twice — to learn the rules and to test the models — so it is rotated through 5 folds. A study never appears in both roles within a fold. Splits are frozen and hashed before any training.
